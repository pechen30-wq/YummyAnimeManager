# Руководство пользователя YummyAnime Manager

Актуально для версии **4.5.4**. Программа работает в Windows и скачивает доступные видео по ссылке на страницу аниме YummyAnime. Можно выбрать плеер, сезон, озвучки, серии и качество, а также собрать MKV для Plex.

## 1. Установка и запуск

### Готовое приложение

1. Откройте [репозиторий](https://github.com/pechen30-wq/YummyAnimeManager) и скачайте `dist/YummyAnimeManager.exe`.
2. Сохраните EXE в папку, в которой есть право записи: это нужно для автоматического обновления.
3. Запустите `YummyAnimeManager.exe`. Устанавливать Python для этого способа не требуется.
4. Если Windows показывает предупреждение о файле из Интернета, проверьте, что файл получен из указанного репозитория. Контрольная сумма опубликована в `dist/SHA256SUMS.txt`.

### Запуск из исходников

1. Установите Python 3.11 или новее.
2. Скачайте исходники репозитория или клонируйте его.
3. Один раз запустите `install.bat`: он создаст `.venv` и установит зависимости.
4. В дальнейшем запускайте `run.bat`.

Для объединения нескольких озвучек в один MKV дополнительно установите **MKVToolNix**. Путь к `mkvmerge.exe` можно указать в «Настройках». Для сетевых потоков программа использует FFmpeg, поставляемый с `imageio-ffmpeg`.

## 2. Первый запуск

### Как получить публичный токен YummyAnime

1. Войдите в свою учётную запись YummyAnime на сайте. Если учётной записи нет, сначала зарегистрируйтесь.
2. Откройте [страницу приложений YummyAnime](https://ru.yummyani.me/dev/applications).
3. Создайте новое приложение и заполните обязательные поля формы. Название можно выбрать своё, например `YummyAnime Manager`.
4. После создания откройте запись приложения и скопируйте **публичный токен**. Если страница показывает также приватный токен, его копировать не нужно.
5. В YummyAnime Manager откройте «Настройки», вставьте скопированный токен в поле **«Публичный токен (X-Application)»** и нажмите «Сохранить».

Для работы программы нужен именно токен приложения, который API принимает в заголовке `X-Application`. Токен входа в аккаунт и приватный токен приложения для этого поля не подходят. Не публикуйте свои токены в сообщениях об ошибках и на GitHub. Если страница приложений временно недоступна, повторите попытку позже.

При необходимости проверьте в «Настройках» язык и пути к `mkvmerge.exe` и `ffmpeg.exe`. Без публичного токена список аниме получить нельзя.

Настройки сохраняются в `%USERPROFILE%\.yummy_anime_manager\config.json`. Папка загрузки выбирается в основном окне.

## 3. Загрузка серий

1. Скопируйте адрес страницы аниме из каталога YummyAnime, вставьте в верхнее поле и нажмите «Загрузить». Можно также ввести только идентификатор страницы (slug). Раскрывающийся список поля хранит до 10 последних введённых ссылок.
2. Дождитесь загрузки списка плееров. Если среди них есть **CVH**, он выбирается автоматически. Любой другой плеер можно выбрать вручную.
3. Выберите сезон. Ниже отметьте нужные озвучки из общего списка всех плееров. Плеер определяет только источник видео; аудиодорожки берутся из любых плееров. Список серий показывает серии, доступные в выбранном источнике видео и **во всех** отмеченных озвучках. Для сборки из разных источников нужен MKVToolNix, даже если выбрана одна озвучка.
4. Отметьте серии и дождитесь проверки доступного качества. Выберите «Лучшее доступное» либо конкретное качество.
5. Выберите папку «Куда» и нажмите «Скачать». Два индикатора показывают ход текущей серии и всей очереди.

Наличие серии на странице ещё не гарантирует работающую ссылку на видео. Если источник недоступен или не распознан, программа покажет причину. Прерванные сетевые загрузки повторяются ограниченное число раз. Для прямого файла программа продолжит частично скачанное, если сервер поддерживает HTTP Range.

## 4. MKV, озвучки и Plex

- **«Объединить озвучки в один MKV»** доступно при выборе нескольких озвучек. Программа берёт видео из первой выбранной озвучки и добавляет аудиодорожки остальных. Для этого нужен `mkvmerge.exe`.
- **«Сохранять исходные файлы после сборки MKV»** оставляет промежуточные файлы для проверки; иначе после успешной сборки они удаляются.
- **«Добавлять главы из видео или AniSkip»** сначала переносит главы исходного видео. Если их нет, программа ищет подходящие метки вступления, концовки и краткого пересказа. Когда надёжных меток не найдено, главы не добавляются.
- **Plex-структура** раскладывает файлы по папкам сериала и сезона. **`.plexmatch`** помогает Plex сопоставить сериал с метаданными. Эти параметры можно включать отдельно.

## 5. Автоматическое обновление

Параметр «Проверять обновления при запуске» включён по умолчанию и доступен в «Настройках».

- При запуске **EXE** программа проверяет версию на GitHub в фоне. Если есть новая версия, она предлагает скачать её. Файл сверяется по размеру и SHA-256, затем после выхода из программы заменяется и приложение запускается снова. Для замены требуется право записи в папку EXE.
- При запуске **`run.bat`** проверяются исходники. Чистая Git-копия на ветке `main` обновляется через Git; отдельная папка обновляется из проверенного архива. `.venv`, настройки и загруженные видео сохраняются. При недоступности GitHub запускается установленная версия.
- Для разового запуска BAT без проверки установите переменную окружения `YUMMY_SKIP_UPDATE=1`.

Если автоматическое обновление не удалось, скачайте новую версию вручную из репозитория. Для EXE полезно также проверить, что антивирус или другая запущенная копия приложения не удерживает файл.

## 6. Диагностика неполадок

В «Настройках» включите **«Подробный журнал для диагностики ошибок»**, повторите проблему и нажмите «Открыть папку логов». Журналы находятся в `%USERPROFILE%\.yummy_anime_manager\logs`, ограничены по размеру; параметры URL в записях скрываются.

Типичные случаи:

| Сообщение или симптом | Что проверить |
| --- | --- |
| Нет списка аниме | Публичный токен `X-Application`, адрес страницы, доступ к YummyAnime и Интернету. |
| Нет нужной серии или озвучки | Плеер, сезон и доступность серии во всех выбранных озвучках. |
| Не удалось собрать MKV | Установлен ли MKVToolNix и указан ли путь к `mkvmerge.exe`. |
| Сбой загрузки после повторов | Доступность самого источника; попробуйте другой плеер или время, сохраните журнал. |
| Не работает Alloha | Локальный resolver, Chromium и при необходимости Node.js устанавливаются автоматически. Дождитесь первой установки; при сбое проверьте Интернет и журнал `alloha-install.log`. Удалённый resolver обслуживается вручную. |

Не публикуйте журнал целиком, пока не проверили его на личные данные и токены.

## 7. Ограничения

Программа не обходит DRM. Используйте её только для контента, который вправе сохранять. Качество и доступность видео зависят от сторонних плееров и серверов.

### Загрузка дополнительных озвучек

Видео скачивается из выбранного плеера. Дополнительные озвучки сохраняются в MKA без перекодирования. Если HLS-источник предоставляет отдельный аудиопоток, загружается только он. Если звук встроен в общие видеосегменты или файл, объём получаемых данных зависит от источника; гарантировать загрузку только звуковых байтов нельзя. Озвучка, уже содержащаяся в основном видео, повторно не скачивается.
