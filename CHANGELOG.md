# Changelog

## 4.5.8
- В списке озвучек показаны все доступные плееры; названия дорожек хранятся отдельно от подписей интерфейса.
- Для видео выбирается одна из отмеченных озвучек выбранного плеера, даже когда первая отмеченная озвучка доступна только в другом плеере.
- Звук такой озвучки используется из скачанного видео без повторной загрузки; это отображается в прогрессе и журнале.
- Прямое видео CVH скачивается проверенными блоками по 1 МБ с постоянным соединением; в журнале фиксируется время загрузки.

## 4.5.7
- При сетевом обрыве прямого MP4 во время извлечения дополнительной озвучки обновляется ссылка и включается резервная загрузка блоками по 1 МБ.
- Каждый блок проверяется по Content-Range и длине; повторяется только незавершённый блок. Изменение размера или ETag останавливает сборку.
- Аудио извлекается без перекодирования из полного локального MP4; временный MP4 удаляется после обработки.
- Серверы без Range поддерживаются через проверяемую полную загрузку при известном размере.

## 4.5.6
- HLS-сегменты загружаются в четыре потока с постоянной HTTP-сессией на каждый поток.
- Число повторов сетевого сбоя одного сегмента уменьшено до двух; резервный источник той же озвучки пробуется до повторного обращения к проблемному источнику.
- Обновление ссылок Alloha выполняется последовательно для всех потоков; повторяющиеся ключи/инициализационные сегменты скачиваются один раз.
- Сохраняются завершённые сегменты, порядок плейлиста и проверки полноты; очередь останавливается при неисправимом сбое.
- В журнале фиксируются время HLS-загрузки, количество фрагментов и объём данных.

## 4.5.5
- Исправлен Kodik HTTP 500: первичная загрузка iframe не передаёт выдуманный Referer, из-за которого плеер формировал нерабочие параметры запроса.
- Запросы resolver-ов и проверка обновлений повторяются после временных TLS/сетевых обрывов и HTTP 429/5xx с ограниченным числом попыток.
- Локальный Alloha resolver повторно проверяется и запускается после отказа соединения во время получения ссылки.
- Проверки качества объединены при быстрых изменениях выбора и выполняются последовательно.
- Aksor: одна и та же отсутствующая ссылка не проверяется многократно; отсутствие файлов явно отображается в интерфейсе.
- Резервные варианты видео ограничены выбранным плеером; его фактическая озвучка не подменяет выбранную аудиодорожку.
- Закрываются каналы вывода FFmpeg/MKVToolNix после завершения.

## 4.5.4
- Исправлено зависание перед загрузкой дополнительной озвучки из MP4 без указанной длительности: определение длительности больше не загружает весь видеофайл в память.
- Проверка HLS/DASH-плейлистов ограничена по размеру; ответ в виде большого медиафайла не буферизуется целиком.
- Показаны открытие аудиопотока и полученная длительность при неизвестной общей длительности.

## 4.5.3
- Дополнительные озвучки сохраняются сразу в аудиофайлы MKA без перекодирования.
- Для HLS выбирается отдельный аудиоплейлист, когда источник его предоставляет; видеосегменты такого потока не загружаются.
- Потоки видео исключаются из обработки дополнительных озвучек; звук основного видео используется повторно.
- Экономия трафика зависит от источника: общие аудио/видеосегменты всё равно приходится загружать.

## 4.5.2

- Сетевой обрыв видеосегмента больше не завершает локальный resolver аварийно.
- Неполное видео не считается успешно скачанной серией.
- Аудиодорожки повторно пробуются в других плеерах; звук выбранного видео используется без повторного скачивания.
- Проверка качества больше не закрывает общую сессию Alloha.
