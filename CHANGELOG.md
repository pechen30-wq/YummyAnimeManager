# Changelog

## 4.3.0
- История десяти последних ссылок в выпадающем списке.
- Включаемый подробный журнал с ротацией и скрытием параметров URL.
- Перенос глав из исходного видео в MKV; при отсутствии глав — поиск OP/ED/recap по AniSkip.

## 4.2.1
- Прямые видеофайлы повторно скачиваются после временных сетевых обрывов.
- Частичная загрузка продолжается через HTTP Range, если сервер подтверждает смещение.
- Повторы FFmpeg для HLS/DASH ограничены; при окончательном сбое показывается причина.

## 4.2
- Исправлена обработка Aksor CDN `Error number -138`.
- Реальная сетeвая проверка Aksor URL перед использованием.
- До 3 обновлений Aksor API/CDN edge.
- Fallback через player-page `video_url`.
- Fallback через обнаруживаемый `/api` path из player scripts.
- Системный HTTP/HTTPS proxy явно передаётся FFmpeg.
- Включён FFmpeg reconnect для HLS/DASH.
- Проблемная Aksor-серия автоматически перерезолвится до 3 раз.
- Частичный файл удаляется перед повторной загрузкой.

## 3.2

- В `.plexmatch` записываются Title и Year из YummyAnime.

## 3.1
- Убран длинный путь `Anime / Player / Dubbing`.
- По умолчанию используется Plex-структура `Anime / Season XX / Anime - SxxEyy.ext`.
- Добавлен выбор номера сезона.
- Можно отключить папку `Season XX` и сохранять непосредственно в папку аниме.
- Multi-audio MKV больше не складываются в отдельную папку `Multi-audio`.
- Для аудиодорожек MKV выставляется язык `rus`.
- Первая выбранная озвучка становится аудиодорожкой по умолчанию.
- Имена озвучек сохраняются в названиях аудиодорожек.
