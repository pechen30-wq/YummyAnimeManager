# Changelog

## 4.5.3
- Дополнительные озвучки сохраняются сразу в аудиофайлы MKA без перекодирования.
- Для HLS выбирается отдельный аудиоплейлист, когда источник его предоставляет; видеосегменты такого потока не загружаются.
- Потоки видео исключаются из обработки дополнительных озвучек; звук основного видео используется повторно.
- Экономия трафика зависит от источника: общие аудио/видеосегменты всё равно приходится загружать.

## 4.5.2
- Alloha: скачивание всех HLS-сегментов с обновлением истёкших ссылок и сохранением завершённых сегментов между попытками.
- Сетевой обрыв видеосегмента больше не завершает локальный resolver аварийно.
- Неполное видео не считается успешно скачанной серией.
- Аудиодорожки повторно пробуются в других плеерах; звук выбранного видео используется без повторного скачивания.
- Проверка качества больше не закрывает общую сессию Alloha.

## 4.5.1
- Исправлено зависание загрузки Alloha и других HLS/DASH-источников: FFmpeg больше не переподключается при нормальном конце плейлиста или сегмента.
- Добавлен регрессионный тест реального скачивания конечного HLS-видео.

## 4.5.0
- Общий список озвучек из всех плееров; смена источника видео сохраняет выбор аудиодорожек.
- Видео из выбранного плеера и аудиодорожки из любых источников собираются в MKV.
- Качество выбирается для видео независимо от качества источников аудио.
- Автоматическая установка и фоновый запуск локального Alloha resolver, Chromium и переносного Node.js при необходимости.

## 4.4.1
- Временные обрывы TLS-соединения при запросе аниме и серий к YummyAnime API повторяются с ограниченной задержкой.
- После исчерпания попыток показывается понятное сообщение с технической причиной.

## 4.4.0
- Проверка обновлений при запуске EXE и BAT, скачивание с проверкой SHA-256.
- CVH выбирается по умолчанию, когда доступен; ссылка-пример удалена из поля ввода.
- Подробная инструкция пользователя.

## 4.3.0

- Включаемый подробный журнал с ротацией и скрытием параметров URL.
- Перенос глав из исходного видео в MKV; при отсутствии глав — поиск OP/ED/recap по AniSkip.

## 4.2.1

- Повторы FFmpeg для HLS/DASH ограничены; при окончательном сбое показывается причина.
